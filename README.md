# Sistema de Control de Rescate y Adopción

Prototipo académico de tres páginas desarrollado únicamente con HTML5.

## Archivos
- `index.html`: página principal.
- `reportar.html`: formulario con validación nativa del navegador.
- `rescates.html`: tabla con registros ficticios de ejemplo.

## Cómo probarlo
Abra `index.html` en un navegador y use el menú para visitar las otras páginas.

## Importante
El formulario demuestra validación HTML5, pero no almacena ni envía información a un servidor.
La tabla contiene datos ficticios y no se actualiza automáticamente.

## Validación
Valide cada archivo en https://validator.w3.org/ usando la opción File Upload.

## GitHub
Cree una rama llamada `feature/maquetacion-html` y suba los tres archivos.
